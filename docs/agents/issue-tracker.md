# Issue tracker: GitHub

Issues and specifications for this repository live in GitHub Issues.
Use `gh` for tracker operations in `Bricesodini/retro-gaming`.

- Read an issue, including comments: `gh issue view <number> --repo Bricesodini/retro-gaming --comments`
- List open issues: `gh issue list --repo Bricesodini/retro-gaming --state open`
- Create or update issues only when the task authorizes tracker writes.
- GitHub native issue dependencies are authoritative for blockers; verify them before dispatch.
- Pull requests are not a triage request surface.
