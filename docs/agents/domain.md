# Domain docs

## Before exploring

Read the root `CONTEXT.md`, then read relevant decisions in `docs/adr/` if that directory exists. This repository uses a single-context domain layout.

## Vocabulary

Use the terms defined in `CONTEXT.md` in issues, code, tests, and reports. In particular, Elf is the ally who intervenes during the possession; do not reintroduce the former robot character.

## Decisions

Surface conflicts with documented domain decisions instead of silently overriding them. Add or change domain definitions and decisions through the domain-modeling workflow when needed.
